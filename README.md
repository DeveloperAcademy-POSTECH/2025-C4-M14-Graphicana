## 🎮 Game Introduction
Ttouch Island는 섬에 다다르다는 탐험적 의미와, `땃쥐(Ttaji)` + `Touch`라는 주인공의 흔적을 담아낸 이름에서 시작된 3D 플랫포머 게임입니다.  
몰디브의 실제 수몰 위기라는 환경 문제를 배경으로, 아름다운 자연 속에 숨겨진 위협과 생존의 긴장감을 탐험을 통해 그려내고자 합니다.

## 📚 Git Convention Guide

이 저장소에서는 효과적인 협업과 일관된 코드 관리를 위해 [Git Convention](https://github.com/DeveloperAcademy-POSTECH/2025-C4-M14-Graphicana/wiki/%F0%9F%8E%B2-Git-Convention) 문서를 따르고 있습니다.

- **브랜치 전략:** Git-Flow를 기반으로 `main`, `develop`, 그리고 `feat/#이슈넘버` 형식의 feature 브랜치를 사용합니다.
- **이슈 생성:** 모든 작업은 이슈 생성 후 시작합니다.
- **커밋 컨벤션:** 명확한 타입, 간결한 제목, 필요시 본문을 포함해 작성합니다.
- **PR 네이밍:** 명사 형태로 작성하며, 기능 단위로 구분합니다.
- **코드 리뷰:** PR 머지 전 1명 이상의 Approvals가 필요합니다.

**예시**
- feat: 로그인 화면 추가
- fix: 홈 진입 시 크래시 수정
- refactor: 데이터 모델 구조 정리

자세한 내용은 아래 링크를 참고하세요.  
👉 [Git Convention 바로가기](https://github.com/DeveloperAcademy-POSTECH/2025-C4-M14-Graphicana/wiki/%F0%9F%8E%B2-Git-Convention)

## 📝 Code Convention Guide

이 저장소의 코드는 [Code Convention](https://github.com/DeveloperAcademy-POSTECH/2025-C4-M14-Graphicana/wiki/%F0%9F%93%9D-Code-Convention) 문서를 기반으로 작성됩니다.

- **Swift 스타일 가이드:** Apple Developer Academy의 공식 Swift 스타일 가이드를 따릅니다.
- **네이밍 규칙:** 변수, 함수, 열거형, 클래스, 프로토콜 등 각 요소별 명확한 네이밍 원칙을 적용합니다.
- **주석 작성:** 간결하고 명확한 주석, 퀵헬프, MARK, TODO/FIXME 활용을 권장합니다.
- **코드 스타일:** 4칸 들여쓰기, 공백 및 콜론 규칙, 타입 추론과 어노테이션, 파일 import 정렬 등 세부 규칙을 준수합니다.
- **SwiftUI:** View는 struct로 정의하고, 레이아웃 컨테이너 사용 원칙을 지킵니다.

자세한 코딩 컨벤션과 예시는 아래 링크에서 확인할 수 있습니다.  
👉 [Code Convention 바로가기](https://github.com/DeveloperAcademy-POSTECH/2025-C4-M14-Graphicana/wiki/%F0%9F%93%9D-Code-Convention)
